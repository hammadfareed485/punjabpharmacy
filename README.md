# Punjab Pharmacy (پنجاب فارمیسی) - Complete Online Medicine Purchasing Platform

ایک مکمل، خوبصورت اور پروفیشنل آن لائن فارمیسی ویب سائٹ جو خاص طور پر ادویات اور ہیلتھ کیئر پراڈکٹس کی آن لائن خریداری (Purchasing & Ordering) کے لیے تیار کی گئی ہے۔

---

## 🌟 اہم خصوصیات اور فنکشنز (Key Features & Functions)

1. **آن لائن میڈیسن کیٹلاگ (Medicine Catalog & Inventory):**
   - مستند ادویات بشمول پیناڈول، اگمینٹن، بروفین، رائسیک، سربیکس زی، کیلشیم اور بی پی / شوگر مانیٹرنگ ڈیوائسز۔
   - زمرہ جات (Categories): درد و بخار کی ادویات، معدہ اور ہاضمہ، وٹامنز و سپلیمنٹس، میڈیکل آلات، مدر اینڈ بیبی کیئر، فرسٹ ایڈ و پٹیاں۔
   - فلٹرز: کیٹیگری فلٹر، نسخہ لازمی (Rx Only)، قیمت اور حروفِ تہجی کے لحاظ سے ترتیب (Sorting)۔

2. **ڈاکٹر کا نسخہ اپ لوڈ کرنے کی سہولت (Prescription Upload System - نسخہ بھیجیں):**
   - مریض یا گاہک اپنے ڈاکٹر کے نسخے کی تصویر (Photo / Scan) براہِ راست اپ لوڈ کر سکتا ہے۔
   - فارماسسٹ ریویو سسٹم: کوالیفائیڈ فارماسسٹ نسخے کی تصدیق کر کے 15 منٹ میں رابطہ کرتا ہے۔

3. **انٹرایکٹو کارٹ اور ڈسکاؤنٹ سسٹم (Smart Shopping Cart):**
   - کارٹ سلائیڈ آؤٹ دراز (Drawer)۔
   - مقدار میں کمی یا بیشی (+ / -)۔
   - فری ہوم ڈیلیوری پروگریس بار (1500 روپے سے زائد کے آرڈر پر مفت ڈیلیوری)۔
   - پرومو کوڈ / کوپن سسٹم (مثلاً `PUNJAB10` لگانے سے 10% رعایت)۔

4. **مکمل چیک آؤٹ اور آرڈر پلیسمنٹ (Checkout & Ordering):**
   - صارف کا نام، فون / واٹس ایپ نمبر، شہر (لاہور، اسلام آباد، راولپنڈی، فیصل آباد، ملتان وغیرہ) اور مکمل پتہ۔
   - ادائیگی کے طریقے (Payment Options):
     - کیش آن ڈیلیوری (Cash on Delivery - COD)
     - جاز کیش / ایزی پیسہ (JazzCash / Easypaisa)
     - بینک ٹرانسفر یا کارڈ (Bank Transfer / Card)
   - نسخہ وارننگ الرٹ: اگر کارٹ میں کوئی پریسکرپشن میڈیسن (Rx) ہو تو چیک آؤٹ پر فوری آگاہی۔

5. **فوری آرڈر رسید اور واٹس ایپ کنفرمیشن (Order Invoice & WhatsApp Integration):**
   - آرڈر ہوتے ہی یونیک ریفرنس نمبر ملتا ہے (مثلاً `#PP-2610-A9B2`)۔
   - آفیشل پرنٹ ایبل رسید (Printable Invoice)।
   - ایک کلک سے واٹس ایپ پر آرڈر کی مکمل تفصیلات بھیجنے کا بٹن۔

6. **لائیو آرڈر ٹریکنگ (Live Order Tracking):**
   - آرڈر آئی ڈی یا فون نمبر درج کر کے لائیو اسٹیٹس چیک کریں:
     `Order Placed` -> `Pharmacist Check` -> `Packed in Cold-Box` -> `Out for Delivery` -> `Delivered`

7. **فارماسسٹ ایڈمن پورٹل (Pharmacist & Admin Dashboard):**
   - نیویگیشن بار سے "Pharmacist Portal" پر کلک کریں۔
   - کل آرڈرز، کل فروخت (Revenue)، اور زیرِ التواء نسخہ جات کے لائیو اعدادوشمار۔
   - گاہکوں کے تمام آرڈرز کی لسٹ اور اسٹیٹس تبدیل کرنے کا اختیار۔
   - اپ لوڈ کردہ نسخوں کی تصویر اور تفصیلات دیکھنے کی سہولت۔

8. **24/7 ایمرجنسی ہیلپ لائن اور واٹس ایپ چیٹ:**
   - اسکرین پر تیرتا ہوا (Floating) واٹس ایپ بٹن جس سے گاہک فوری فارماسسٹ سے بات کر سکتا ہے۔

## 🚀 چلانے کا طریقہ (How to Run)

### طریقہ 1: ڈبل کلک کر کے (One-Click Launch)
- فولڈر میں موجود `run.bat` فائل پر ڈبل کلک کریں!
- سرور خود بخود شروع ہو جائے گا اور براؤزر میں `http://127.0.0.1:5000` اوپن ہو جائے گا۔

### طریقہ 2: ٹرمینل کے ذریعے (Via Terminal / Command Prompt)
```bash
python app.py
```
اور اپنے انٹرنیٹ براؤزر (Chrome, Edge, Firefox) میں کھولیں:
```
http://127.0.0.1:5000
```
